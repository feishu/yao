下面把 `go.mod` 里出现的**每一个直接依赖**（`require` 块）按字母序拆开说明：

- **它是干什么的**  
- **典型用途 / 在 Yao 框架里可能的角色**  
- **主要优缺点**（是否值得替换、是否有坑）

---

### 1. github.com/PuerkitoBio/goquery v1.10.1  
**用途**：服务器端的 jQuery，用 Go 解析和操作 HTML/XML（CSS 选择器、DOM 遍历）。  
**在 Yao**：爬虫、报表导出、富文本清洗、低代码「HTML 模板字段」等。  
**优点**：API 接近 jQuery，上手快；支持 XPath/CSS 选择器；活跃维护。  
**缺点**：依赖 `golang.org/x/net/html` 解析器，大文件内存占用高；**不是流式**，>50 MB 网页会卡顿。

---

### 2. github.com/aws/aws-sdk-go-v2 + 子模块（credentials、s3…）  
**用途**：AWS 新一代官方 SDK（v2），支持 S3、DynamoDB、STS 等。  
**在 Yao**：「对象存储」驱动、私有部署备份、插件市场文件上传。  
**优点**：模块化引用（只编译用到的服务），**HTTP 复用 + 中间件**；支持 **Endpoint 自定义**（兼容 MinIO、Ceph）。  
**缺点**：v1 → v2  Breaking Change 多；**包体积大**（>15 MB 静态编译）。

---

### 3. github.com/blang/semver v3.5.1+incompatible  
**用途**：语义化版本解析/比较（Major.Minor.Patch）。  
**在 Yao**：插件/框架自身版本号校验、依赖冲突检测。  
**优点**：API 简洁，**无反射**；支持 **约束表达式**（`^1.2.3`）。  
**缺点**：已停止维护；官方推荐 `github.com/Masterminds/semver/v3`。

---

### 4. github.com/caarlos0/env/v6 v6.10.1  
**用途**：把环境变量一次性绑定到结构体字段（tag 驱动）。  
**在 Yao**：docker/helm 部署时注入数据库、Redis、JWT 密钥等配置。  
**优点**：支持嵌套、默认值、类型转换；**无 init 副作用**。  
**缺点**：字段很多时 **首次反射慢**；**不支持热更新**（需重启进程）。

---

### 5. github.com/cenkalti/backoff/v4 v4.2.1  
**用途**：指数退避 + 抖动重试库（支持永久重试、上下文取消）。  
**在 Yao**：插件市场下载失败、数据库闪断、第三方 API 调用。  
**优点**：Context 感知；**支持自定义退避方程**；线程安全。  
**缺点**：**重试次数上限需自己传**，否则可能 **无限 spin**。

---

### 6. github.com/clbanning/mxj/v2 v2.7.0  
**用途**：任意 XML ↔ Map 互转（类似 `encoding/xml` 的懒人版）。  
**在 Yao**：Excel/CSV 导出时把 **XML 数据源** 转 JSON 给前端；低代码「SOAP 接口」插件。  
**优点**：**不依赖结构体**；支持属性、命名空间。  
**缺点**：**大 XML (>10 MB) 全 DOM 加载**，内存爆炸；**无流式 API**。

### 9. github.com/evanw/esbuild v0.25.4

### 38. 一句话总结

- **Yao 直接依赖** 已覆盖 **Web、数据库、支付、Excel、V8、国际化、CLI、升级、测试** 全链路；  
- **go-json + sonic + jsoniter** 三重加速 → **JSON 全链路 3× 提速**；  
- **间接依赖** 由 **go.mod 自动最小化**；**升级前只需 `go mod tidy`** 即可。
